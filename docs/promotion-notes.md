## Short Sharing Note

This repository is a practical Azure Services Cheat Sheet focused on
architecture and integration decisions rather than generic product summaries.

It covers Azure Service Bus, Azure Functions, API Management, Logic Apps, Blob
Storage, Key Vault, Managed Identity, Azure DevOps, monitoring, production
readiness, and Dataverse / Dynamics 365 integration patterns.

Repository:
[Azure Services Cheat Sheet](https://github.com/brunsdon/azure-services-cheat-sheet)
